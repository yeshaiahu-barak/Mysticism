# הפרופיל המיסטי שלי 🌙

אפליקציית רשת (PWA) מתקדמת המפיקה דוח מיסטי אישי ומקיף הכולל חישובי נומרולוגיה, גימטריה ואסטרולוגיה (כולל אופק ותאריכים עבריים).

## תכונות מרכזיות (Features)
* **חישובים מקיפים:** גימטריה ונומרולוגיה לשם פרטי, שם משפחה, תעודת זהות, מספר טלפון ותאריך לידה.
* **אסטרולוגיה מדויקת:** משיכת קואורדינטות לפי עיר לידה ושעת שקיעה כדי לחשב מזל שמש, אופק מדויק ותאריך לידה עברי הלכתי.
* **ייצוא ושיתוף:** אפשרות לייצא את הדוח המעוצב ישירות ל-PDF (מותאם לעברית) או לשתף ב-WhatsApp בלחיצת כפתור.
* **PWA - Progressive Web App:** האפליקציה תומכת בהתקנה ישירה על מסך הבית במכשירים ניידים (iOS/Android).
* **עיצוב מודרני:** ממשק משתמש נקי, מותאם אישית וידידותי לנייד (Responsive).

## טכנולוגיות (Tech Stack)
* HTML5
* CSS3 (Flexbox & Print Media Queries)
* Vanilla JavaScript (ES6+)
* שילוב APIs חינמיים: 
  - `Nominatim` (להמרת ערים לקואורדינטות)
  - `Sunrise-Sunset` (למציאת שעת השקיעה)
  - `Hebcal` (להמרת תאריכים לועזי-עברי)

## איך להתקין ולהפעיל
1. שכפל את המאגר (Clone) למחשב שלך או הורד את הקבצים.
2. פתח את הקובץ `index.html` בדפדפן שלך.
3. להפעלת האפליקציה ברשת והתקנתה על הנייד, מומלץ לאחסן את הקבצים בחינם באמצעות [GitHub Pages](https://pages.github.com/).

## מונטיזציה (בקרוב)
* מנגנון פרימיום מובנה המאפשר נעילת "הפקת דוח עמוק" מאחורי חומת תשלום.
