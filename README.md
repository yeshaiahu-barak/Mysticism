# 🌌 מערכת הדוח המיסטי והנומרולוגי

אפליקציית ווב מתקדמת המספקת למשתמשים דוח אישי מקיף המשלב אסטרונומיה, לוח שנה עברי ונומרולוגיה עתיקה, הכל בהתאמה אישית מלאה.

## 🚀 תכונות מרכזיות
* **ניתוח אסטרונומי ועברי:** 
  * המרה מדויקת של תאריך לידה לועזי לעברי, תוך התחשבות גיאוגרפית בשעות השקיעה המקומיות (באמצעות APIs פתוחים של תנועת השמש).
  * חישוב מזל שמש (Zodiac) קלאסי, וחישוב **מזל אופק** (Ascendant) מדויק המבוסס על שעת הלידה.
* **תורת המספרים והגימטריה:**
  * פירוק שם האדם לערכים גימטריים וצמצומם לספרה בודדת המאפיינת את האישיות.
  * הפקת משמעויות מיוחדות ל"מספר תקשורת" (מבוסס טלפון נייד), "מספר זהות" ו"מספר מזל" (מבוסס תאריך לידה).
* **חוויית משתמש רציפה (Offline First):**
  * יכולת להזין נתונים ולשמור אותם גם כאשר המכשיר אינו מחובר לאינטרנט.
* **ייצוא נוח:**
  * הורדת הדוח המלא כקובץ PDF קריא הכולל אוטומטית את שם המשתמש.
  * שיתוף טקסטואלי ישיר לאפליקציית WhatsApp.

## 🛠 טכנולוגיות בשימוש
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **External APIs:** Hebcal API, Sunrise-Sunset API, Nominatim (OpenStreetMap).
